# Reality-spike cohort

This bounded cohort deliberately challenges the provisional model. Candidate names are discovery seeds only: resolve them against the current authoritative data before acquisition, record the resolved identifiers, and do not assume name, ABN, ACNC record or public-facing organisation are one-to-one.

The cohort is not a representative national sample and is not a public ranking or endorsement list. Add source URLs, retrieval dates, access constraints, failures and model observations to local runtime/processed artefacts, not this repository.
