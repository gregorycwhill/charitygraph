# CharityGraph Build and Publication Contract

**Status:** Canonical Builder operational contract  
**Scope:** validated release candidates; no direct public publication authority

## Principle

A successful processing run is not automatically publishable. Builder assembles a complete ReleaseProjection from governed observations, coverage and derivatives; Data owns immutable public release artefacts; Viewer renders a selected release.

## Candidate boundary

A candidate is written only to an isolated runtime staging location. The allowlist admits declared public representations, schemas, manifests, licence/attribution material, capability definitions, source-safe references and approved governance projections. It excludes raw reports, website snapshots, prompts, model responses, private corrections, caches, telemetry, credentials, logs and debug output.

## Acceptance

A candidate must pass software and contract tests; identity/binding invariants; evidence and derivative-lineage resolution; model-method/policy labels; domain-policy checks; coverage/assessment-scope and anti-sparsity checks; cohort-budget reconciliation; taxonomy validation; source-rights and privacy checks; declared bulk/JSON/Markdown consistency; drift/anomaly review; manifest/hash verification; and previous-valid-release preservation.

Fundraising expenditure may be null only with explicit valid coverage. Source-reported campaign metrics retain wording, period and scope; they do not become ROI or accounting reconciliation.

## Distribution handshake

Builder provides a complete validated candidate and acceptance report. Data verifies and owns immutable release bytes, manifest, current-release pointer and public contract. Viewer verifies the selected release, public routes, alternates, source links, sitemap, robots and presentation fidelity. A failed candidate or deployment never replaces the previous valid release.

Public contract 0.5 is immutable compatibility. Builder may project fixtures through its explicit adapter but must not edit or regenerate the named release in place.
