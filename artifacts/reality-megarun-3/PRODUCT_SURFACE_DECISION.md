# Product surface decision

Use a progressive card with an evidence ledger, not a self-contained dossier and not a flat fact sheet.

The card answers the common, scoped question first. It must show current/historical context, source-role and reporting-period labels, a non-comparable badge where appropriate, and a visible review badge for candidates. Expansion opens an evidence ledger containing locator, scope, valid time, source, review state, comparison class and any reviewed supersession link.

Candidate visibility is permitted only as clearly marked attributed material; default card claims must remain governed/retained. A dossier is a secondary research/export view, appropriate for deep evidence and unresolved comparison, not the default discovery surface.

Batch semantics should create and govern reusable propositions and comparison classifications. Query-time work should only select, filter and order them deterministically. This minimizes divergent interpretation and allows the same ledger to explain several product lenses.
