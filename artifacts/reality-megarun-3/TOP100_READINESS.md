# Top-100 readiness

## Status: not ready

The largest barrier is not card rendering; it is representative, auditable evidence coverage with honest missingness across all 20 North Star sections. This experiment has five retained subjects, no raw report/page denominator, no acquisition or extraction failure ledger, zero explicit abstentions, and no query-test suite.

Top-100 readiness requires a cohort ledger that reports, per section and source family: subjects attempted/completed; sources acquired/failed; pages/chunks represented; propositions/candidates/abstentions; missingness basis; review units and rate; comparison and query tests; and failure taxonomy. It must include difficult reports, nonstandard periods, unavailable sources, sparse organisations and actual correction/conflict cases, rather than only retained successes.

The demonstrated benefit is a safety rail: 16 observed comparison pairs were kept from false conflict. The unknown is whether that rail survives scale, heterogeneous raw documents and user query patterns.
