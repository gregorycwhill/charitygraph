# C — query-time challenger

`retained normalized propositions → user-view section selection (identity, purpose, programmes, beneficiaries, scale, finance, funding) → concise attributed response`

C creates no durable card. The five `C_query_time.md` files demonstrate the upper bound: a readable answer, badges, evidence locators, and an explicit unsupported/unprocessed remainder can be assembled directly at render time.

It is useful for low-risk orientation and exploratory AI context. It is not a safe replacement for durable governed projections: order and selection become view-dependent; corrections must invalidate caches or regenerate every answer; review state is easy to flatten; and two viewers can see materially different summaries from the same propositions.
