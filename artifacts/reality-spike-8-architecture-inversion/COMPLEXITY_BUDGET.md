# Complexity budget

These are architecture counts, not benchmark timings.

|Measure|A actual composed path|B straight line|C query time|
|---|---:|---:|---:|
|Meaningful stages|10|4|3|
|Persistent record families touched|6+|1 envelope + optional coverage|1 envelope|
|Translations / adapters|8–9|2|1–2|
|Decision gates before display|promotion plus validation|status filter only|renderer policy only|
|Materialized artifacts per subject|typed graph, projection, card|envelope, projection, card|none required beyond response|
|New section needs code|assignment + coverage/compiler route|one deterministic route entry|selection policy only|
|New source family needs code|source adapter + candidate/governance path|one envelope adapter after extraction|same as B|
|Disposable implementation lines|~100 Spike-5 bridge plus historical runtime|97|97 shared B/C script|

The measured reduction is about 60% in meaningful stages (10 → 4) and 75% in explicit translations (8–9 → 2) for already-compatible retained propositions. This is a real reduction in phase/interoperability machinery, but it stops at the semantic boundary. A source family with unstructured report claims still needs provenance-preserving extraction, section assignment, risk routing, and review; none of those were bypassed by B.

Top-100: B is plausible for regulator-shaped facts if a single versioned adapter and envelope validator exist. C is plausible as a read model over B, not as the only durable product state. Review workload and correction propagation remain governed-data problems, not card-building problems.
