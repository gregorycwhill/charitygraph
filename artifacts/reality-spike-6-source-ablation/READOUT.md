# Reality Spike 6 — Source ablation and latent report value

`REALITY_SPIKE_6_SOURCE_VALUE_DISCOVERED`

Completed 5/5 subjects × V0–V4 (25 variants), using local retained state only. Zero provider calls, zero network acquisition, zero S0/canonical mutation.

## Finding

The dominant bottleneck is **not using sources already acquired**, conditional on report-rich subjects: V1 adds nothing, while V2’s deliberately bounded semantic interpretation adds 14 sections across World Vision and Red Cross. Regulator data plausibly supports 10–12 orientation sections, but not participation, direct capacity, governance/relationships, ethos/conduct, outcomes or discovery. Annual reports merit a first-class semantic-source experiment; official-web value is unmeasured here because no retained official-web corpus exists. §19 is a stronger candidate for latent/searchable presentation; §§6/7/9/12/15/16/18 should be evidence-led modules, not universal expectations.

## Source-family product-value order

1. ACNC/AIS — broad, reliable baseline. 2. Annual reports — highest latent marginal value, zero current-path value. 3. Historical specialist replay — overlap only. 4. Official web/Wikimedia/PFRA — no retained evidence in this cohort; cannot be ranked empirically.

## Recommended next tranche

**Product-surface redesign**, paired with one bounded report-candidate review workflow: the experiment demonstrates that showing all 20 tiles is poor default UX, while the current product discards the only retained source family capable of filling the most user-meaningful gaps. Do not build new acquisition/OCR/provider machinery.
