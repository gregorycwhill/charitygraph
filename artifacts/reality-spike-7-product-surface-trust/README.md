# Reality Spike 7 — product surface and trust model

`REALITY_SPIKE_7_PRODUCT_TRUST_DISCOVERED`

Disposable product experiment over retained Spike 6 V0/V2/V4 outputs and candidate locators. It made no provider or network calls and did not mutate S0, GitHub, canonical knowledge, or governance policy.

The experiment distinguishes a regulator/source fact, a first-party assertion, a model-extracted report candidate, governed knowledge, and a processing/evidence gap. A report-derived item is never silently recast as independently verified.

The core finding is a **progressive card backed by an evidence-first ledger and a separately constrained AI projection**. P1 attributed-candidate visibility is useful for low-risk descriptive claims, but is not a substitute for promotion in outcome, conduct, relationship, governance-assertion, or promotional-performance contexts.

Inputs: `../reality-spike-6-source-ablation/` (especially `LATENT_REPORT_VALUE.md`, V0/V2 matrix cells, and retained locator references). These outputs are historical and experimental.
