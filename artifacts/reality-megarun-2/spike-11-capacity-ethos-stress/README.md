# Reality Spike 11 — Semantic stress: capacity and ethos

`REALITY_SPIKE_11_CAPACITY_ETHOS_STRESS_DISCOVERED`

This is an evidence-led, non-canonical experiment. It tests the retained proposition envelope described by Spike 8 against North Star §7 (direct service / capacity) and §15 (ethos / values). It creates no source, S0, provider, canonical, authorisation, or GitHub state.

## Input boundary

The workspace contains retained report-candidate material for Australian Red Cross (2024–25 annual report, pp. 2–4) and World Vision Australia (2025 annual report, pp. 1–5), in the Spike 7 dossiers. Those are actual retained evidence summaries, and every report claim below remains first-party and model-extracted pending promotion. No `spike-9` or `spike-10` output exists in the checked-out workspace; consequently no MSF/Bush Heritage report was selected or reconstructed. This is a recorded input absence, not evidence of absence of service, capacity, implementation, or outcomes.

## Result

The unchanged envelope can safely retain and route 11 of 18 candidates (61%) when claims stay attributed and scoped. It loses the semantic difference that makes capacity comparable (5 candidates) and the stage difference that protects values claims (2 candidates). The smallest useful disposable extension is a discriminated `domain_semantics` qualifier, not a second schema: `capacity` carries measurement kind/unit/denominator/period/scope; `ethos` carries assertion stage and commitment type. With it, 15 candidates are expressible without flattening; 3 remain abstentions because evidence is insufficient or not current.
