# Reality Spike 13 — simplified product pipeline A/B

`REALITY_SPIKE_13_SIMPLIFIED_PIPELINE_DISCOVERED`

This disposable experiment compares the best locally evidenced historical path (Spike 8 actual composed path) with a runnable challenger using Spike 12’s G2 proposition envelope:

`retained evidence → attributed candidate proposition → minimal status/relation review → deterministic route/coverage → progressive card + evidence ledger`

Run `python run_experiment.py` from this folder. It reads no providers and only writes this directory.

The fixture corpus contains retained Red Cross, World Vision and Sunrise material. Spikes 9–10 are absent in this checkout, so MSF and Bush Heritage are deliberately represented by `no_compatible_retained_evidence`, not reconstructed facts. This makes missingness fidelity a tested result rather than a gap hidden by a card.

See `A_B_READOUT.md`, `summary.json`, `challenger_ledger.json`, `progressive_card.md`, and `terra_query_simulation.json`.
