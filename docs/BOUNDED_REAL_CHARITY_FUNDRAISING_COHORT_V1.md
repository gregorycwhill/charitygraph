# Bounded real-charity fundraising cohort v1

Status: reproducible private selection audit. This is not a source acquisition, identity-resolution run, prevalence result, public projection, or production ingestion.

Run `python scripts/run_bounded_real_charity_fundraising_cohort.py --output <path>` from the Builder root. The report has two deliberately non-joinable denominators: ten heterogeneous real-charity discovery handles from the retained local cohort configuration, and four anonymous governed review-fixture subjects inherited from the 287 gate.

The ten handles exercise selection diversity only. Every identity, fundraising-evidence, and finance state is `unresolved` or `not_processed`; no source wording, F2F status, campaign, provider, financial amount, or attribution is claimed about any named charity. The four governed review subjects remain the only retained examples for typed lifecycle, campaign/provider separation, aggregate finance non-attribution, and scoped insufficiency. They are not asserted to be any named charity.

This separation is an intentional refusal control. It prevents a familiar real charity name from laundering anonymous fixture evidence into a production fact. The report also records the 287 gate's remaining prerequisite: rights-cleared, identity-bound evidence before real-charity observations or structured financial measurements can be promoted.
