# Fundraising contradiction and negative-control suite v1

**Status:** Local review-only regression suite.  
**Date:** 5 October 2026.  
**Scope:** Mechanical refusal paths for the governed fundraising practice and money contracts. It creates no source acquisition, production ingestion, public promotion, release, or scale authority.

## Denominator and reading rule

The suite has **seven adversarial case families**, represented by seven test functions. Several test functions contain more than one mutation; those executions are not independent charity, identity, source, or assertion denominators. A passing result says only that the named deterministic contract continues to fail closed. It is not a precision, recall, or real-world coverage result.

| Case family | Required outcome |
| --- | --- |
| Regulator permitted-method list and PFRA membership | Blocked; neither becomes evidence of actual F2F practice or currentness. |
| Agency case study with an explicit ended engagement | Retained as discontinued, never current. |
| Generic donate page and annual fundraising cost | Website channel can remain source-native; aggregate cost remains organisation-level with unknown method linkage. |
| Campaign gross, provider-reported raised amount, audited donations | Different measure kinds remain unaddable. |
| Gross/net, group and entity variants | Compatibility fails closed. |
| Same-name or same-domain charity | A money scope link cannot override a subject measurement's reporting entity. |
| Present versus explicitly absent practice | Both candidates remain visible and cross-linked as a contradiction; the compiler does not resolve it. |

The existing inference and lifecycle suites separately retain scoped silence, ambiguous binding, historical material, explicit cessation, unavailable finance and review-only states. Unknown, not-found, unavailable and review-only are valid results rather than failed extractions.

## Execution

Run:

```powershell
python -m pytest tests/test_fundraising_contradiction_negative_controls.py tests/test_fundraising_inference.py tests/test_fundraising_money_scope_linkage.py tests/test_safe_fundraising_financial_derivatives.py -q
```

This suite is an adjunct to the 24-case predecessor regression described in the Data repository's fundraising scale/error gate register. It does not enlarge that empirical denominator.
