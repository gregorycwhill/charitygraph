# Native induction V5 overlay lifecycle (Lab-only)

This branch records the first Native overlay lifecycle reality test after the
V4R reconciliation. It is experiment-only: there is no production Native
persistence or canonical Native catalogue, and the historical PR #48/#50/#51/
#52 archaeology remains separate.

The run starts from retained V4R canonical semantic objects. Native overlays
are optional classifications layered on those objects; they do not compete
with canonical representation. Three whole organisations are used for
training and two unseen organisations are held out until final catalogues are
frozen. Provider calls are sequential, Luna is the primary model (reasoning
none), and Terra is restricted to bounded audit/review roles.

The private runtime contains the split, raw responses and aggregate telemetry;
no evidence or raw provider traffic belongs in this repository. V4 was
orchestration-invalid and V4R was representation-first reality-tested but did
not test facet lifecycle. This branch does not claim Native quality,
prevalence, or production readiness.
